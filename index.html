About Me

I've spent the last 3 years building for the web — moving fluidly between front-end and back-end work, with Drupal as my deep specialization. I like owning a feature end to end: the data model, the API, and the interface on top of it.

My sweet spot is turning messy requirements into clean, maintainable systems — a React front end talking to a solid PHP/Drupal back end, or a fully decoupled build with JSON:API and Next.js. When a project needs Drupal done right (custom modules, performance, migrations), that's where I go deepest.
