About Me

For the past 3 years I have been building web applications with a full-stack approach, specializing in Drupal & PHP as my core expertise. I like owning a feature end to end: the data model, the API, and the interface on top of it.

My strength is turning functional requirements into clear, robust, and maintainable solutions — from the front end with Next.js, Twig, and Tailwind CSS, to the back end with PHP, Drupal, or Laravel, including fully decoupled architectures built on Next.js. When a project calls for deep Drupal expertise — custom modules, performance tuning, or complex migrations — that's where I add the most value.

  • Full-stack feature delivery

  • Decoupled / headless builds
  • Performance & clean code
